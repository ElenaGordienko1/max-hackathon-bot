# MAX Hackathon Bot

## Назначение решения
Чат-бот для мессенджера **MAX**, разработанный в рамках хакатона. Бот помогает пользователям находить интересные мероприятия, основываясь на их предпочтениях. Решение представляет собой MVP рекомендательной системы с возможностью сохранения и изменения пользовательских интересов.

## Основной пользовательский сценарий

### Первое знакомство
1. Пользователь заходит в чат-бот.
2. Бот отправляет приветствие и информацию о себе.
3. Бот собирает интересы пользователя, например:
   *"Выберите категории мероприятий, подходящие вам:*
   1) Спортивные мероприятия
   2) Музыкальные мероприятия
   3) Театр
   4) Искусство и хобби
4. Бот запоминает выбор пользователя.

### Использование
1. Пользователь заходит в чат-бот.
2. Бот приветствует пользователя и отправляет список мероприятий на сегодня, отфильтрованный по его выбору.
3. Пользователь находит подходящее для себя мероприятие.
4. Пользователь может добавить свое мероприятие

## Функции бота (MVP)
1. Запоминание выбора пользователя (сохранение интересов).
2. Возможность изменения выбора пользователя в любой момент.

## Архитектура решения
- **Язык программирования:** Python 3.10+
- **Основная библиотека:** `maxapi` (асинхронная библиотека для MAX Bot API)
- **Хранилище данных:** Локальный JSON-файл (`db_events.json`) для хранения событий и предпочтений пользователей.
- **Конфигурация:** Переменные окружения через файл `.env`
- **Контейнеризация:** Docker + Docker Compose
